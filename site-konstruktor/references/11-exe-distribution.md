# Фаза 9. Раздача программы (если продаётся exe)

## Неподписанный exe
- SmartScreen: «Неизвестный издатель». Chrome: «Подозрительное скачивание» / блокировка. Репутация считается по хешу файла — каждая новая версия начинает с нуля.
- Что делать:
  1. **[П]** Google Search Console: доменный ресурс (TXT рядом с SPF, в кавычках), раздел «Проблемы безопасности».
  2. **После каждой новой версии** — форма Safe Browsing `https://safebrowsing.google.com/safebrowsing/report_error/` с прямой ссылкой на exe, кратким описанием и SHA-256.
  3. Подсказки на сайте (05-site).
- **Подпись кода** — проверять актуальное положение. Справка на конец 2026: OV/EV для самозанятого практически недоступны, оплата из РФ затруднена, облачная подпись Microsoft для РФ недоступна; срок сертификатов сокращён до ~460 дней, EV больше не даёт мгновенного доверия SmartScreen. Альтернатива — Microsoft Store (MSIX). В опыте подпись отложена до появления продаж.

## Чек-лист выпуска версии
1. Сборка скриптом (`.cmd` с журналом, без пауз).
2. **[П]** Установка поверх и живая проверка: окна программы с правами администратора Claude удалённо не проверит.
3. exe + zip + SHA-256 — **пересчитать по файлам**, не брать из старых заданий.
4. Страницы сайта: версия, ссылки, суммы → выкладка в `download/`; старые файлы удалить после переключения ссылок.
5. `DOWNLOAD_URL` в функции (если используется) — с повторным прикреплением zip.
6. Форма Safe Browsing.

## Установщик (Inno Setup 6)
- `AppId` неизменный между версиями.
- Перед установкой: завершить процесс, удалить свои задачи Планировщика (иначе они продолжают запускать старый exe).
- Кладёт руководство и ярлык.

## Защитная программа (урок инцидента)
Крестик окна не закрывает программу — только сворачивает в трей. Выход — с подтверждением; причина завершения пишется в журнал; сторож (задача Планировщика раз в несколько минут) поднимает программу после сбоя, но не после осознанного выхода.
