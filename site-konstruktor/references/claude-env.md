# Как Claude работает с ПК пользователя

Это опыт работы через десктоп-приложение Claude, связанное с облачной сессией. Возможности меняются — сверяться с описаниями доступных инструментов.

## Файлы и команды
- Доступ к папкам ПК — только к подключённым (запросить доступ к рабочей папке проекта один раз).
- Если есть shell на ПК — работать им. Если нет, а есть управление экраном:
  - терминалы и IDE доступны только на клики (печатать нельзя);
  - **метод `.cmd` + Проводник:** Claude кладёт скрипт в подключённую папку (через запись файлов), пользователь или Claude двойным щелчком запускает его в Проводнике, скрипт пишет журнал `*.log` рядом, Claude читает журнал обратно;
  - скрипты без пауз (`pause`), с `chcp 65001`, полными путями и журналом; секреты не выводятся.
- Файлы из облачной песочницы на ПК не появляются сами — их нужно записать в подключённую папку.

## Чего Claude не может
- Окна UAC (защищённый рабочий стол) — подтверждает пользователь.
- Клики и ввод в программах, запущенных от администратора (Windows блокирует ввод из обычных программ).
- Ввод в браузеры пользователя через управление экраном (только просмотр); для сайтов — встроенный браузер Claude или Chrome с расширением.
- Капчи, входы с паролем, 2FA, платежи.
- Доступ к приложениям истекает через ~30 минут без активности — запросить снова.

## Сеть
- Из облачной песочницы сайты пользователя по `curl` обычно недоступны (прокси). Проверка — WebFetch или скрипт на ПК.
- Скриншоты сайта — Playwright в песочнице по опубликованному адресу (если доступен) или локальной копии файлов.

## Работа с телефона
Пользователь может вести проект с телефона, пока ПК включён и приложение Claude открыто. Шаги, требующие ПК (UAC, установка, браузер с входом), — помечать и собирать в пакет «когда будешь у ПК».
