# Грабли (реальные, из запуска)

Формат: что случилось → почему → как не допустить → где проверка.

1. **Бот в Telegram + Cloudflare** → нестабильная связь из Yandex Cloud, трансграничная передача, запреты рекламы → только российские сервисы, свой сайт → фаза 0.
2. **Отказ платёжки** → «VPN», трейдинг, «ключи активации» в описании → нейтральные формулировки → `forms/payment-application.md`.
3. **«Домен за 1 ₽»** → продление в 20+ раз дороже → сравнивать цену продления → фаза 1.
4. **Домен «не работает» после смены NS** → обновление реестра .ru до 24 часов → ждать, не перенастраивать → `nslookup -type=NS`.
5. **Функция «потеряла код»** → правка переменных во вкладке «ZIP-архив» без повторного прикрепления zip → в каждой инструкции «прикрепи zip» → `?r=setup` после правки.
6. **Чистка ПД месяц не работала** → таймер был в коде, но не в облаке → проверять `yc serverless trigger list`.
7. **Письма не уходили** → Postbox принимает SES v2 JSON, а не v1 Query → шаблон `mailer.py`, сверка подписи с botocore.
8. **Письма в спам / SPF пропал** → TXT без кавычек, SPF для Яндекс 360 вместо Postbox, затёрли при правке → кавычки, `spf.postbox.yandexcloud.net`, проверка заголовков письма.
9. **Ключ без оплаты** → сервер принимал тестовое уведомление в боевом режиме и пустой пароль → сверка режимов и 500 на пустой пароль → `tests/test_shop.py`.
10. **Нет чека самозанятого** → не передавали `Receipt` → `RK_RECEIPT=1` → первая боевая покупка, «Мой налог».
11. **Нельзя сделать возврат** → баланс магазина меньше суммы → пополнить баланс → фаза 6.
12. **Сайт обещал СБП и зарубежные карты** → их нет на странице оплаты → сверять способы → фаза 11, п. 6.
13. **Тестовая «покупка» на боевом сайте** → `data-pay="on"` раньше `RK_TEST=0` → только `_claude_pay.cmd` с предохранителем.
14. **Chrome/SmartScreen блокируют exe** → нет подписи и репутации → Search Console, Safe Browsing после каждой версии, подсказки на сайте.
15. **Защитную программу закрыли крестиком** → окно закрывало процесс → трей, подтверждение выхода, сторож.
16. **У посетителей старый вид сайта** → кэш CSS/JS → Ctrl+F5, версия в имени файла.
17. **Модерация затянулась/вопросы** → правили видимое модератору и DNS во время проверки → заморозка на время модерации.
18. **Устаревшие контрольные суммы** → взяли из старого задания → пересчитывать по файлам.
19. **`yc` перестал работать / токен на экране** → вход истекает за 1–2 суток; `yc config list` печатает токен → подтверждение входа в браузере; запрет команды.
20. **Риск потери базы** → сбой зон облака → шифрованные копии до первой оплаты, офлайн-копии по понедельникам, учения восстановления.
21. **Ложная конверсия** → скачивания от песочниц антивирусов → считать «живой запуск → покупка».
22. **Секрет в старой папке** → копия закрытого ключа лежала в рабочей папке → искать и удалять с согласия пользователя.
