# Сайт-конструктор (site-konstruktor)

**Версия 1.0** · скилл для Claude от [Mr Night Lab](https://t.me/mr_night_lab)

Ведёт тебя от нуля до работающего продающего сайта цифрового товара в РФ: домен, Yandex Cloud, сайт, оферта и политика, уведомление в Роскомнадзор, Робокасса с чеками самозанятого, автоматическая выдача товара, резервные копии, боевой запуск. Всё, что может, Claude делает сам. Тебя он зовёт только туда, где нужен именно ты: регистрации, оплаты, входы, подачи заявлений, секреты.

## Откуда он взялся

Из реального запуска: самозанятый продаёт свою программу для Windows через свой сайт. Путь от покупки домена до первой настоящей оплаты занял около трёх недель и собрал два отказа платёжки, дыру «товар без оплаты», найденную аудитом, платёж без чека и таймер, который месяц существовал только в коде. Всё это вошло в скилл как правила и проверки: 22 грабли с причинами и способами не наступить.

## Команды

| Команда | Что делает |
|---|---|
| `Сайт-конструктор` | Анкета о товаре, карта фаз с пометками «делает Claude / делаешь ты», старт |
| `Сайт-конструктор: продолжить` | Продолжает проект с первого незавершённого шага по файлу состояния |
| `Сайт-конструктор: статус` | Что готово, чего ждём, ближайшие сроки |

## Что внутри

```
site-konstruktor/
├── SKILL.md               ← логика ведения проекта
├── references/            ← 15 справочников: фазы 0–12, грабли, работа с ПК
└── templates/
    ├── server/            ← сервер продажи для Cloud Functions (Python) + автотест
    ├── site/              ← двуязычная сборка, форма покупки, «Спасибо», оферта/политика/согласие
    ├── scripts/           ← .cmd для Windows: выкладка, оплата с предохранителем, копии, проверка
    ├── forms/             ← значения для уведомлений РКН и заявки в платёжку
    └── project-state.md   ← файл состояния проекта
```

## Установка

1. Скачай папку `site-konstruktor` из этого репозитория.
2. Упакуй её в ZIP так, чтобы внутри архива лежала папка `site-konstruktor` с файлом `SKILL.md`.
3. Добавь ZIP как пользовательский скилл в разделе скиллов в настройках Claude (название и расположение раздела зависят от версии приложения).
4. Лучше всего работает в приложении Claude, связанном с твоим ПК (Windows): тогда Claude сам запускает скрипты выкладки и проверки. Без этого он готовит файлы и команды, а запускаешь их ты.

## Для кого

- Самозанятый или будущий самозанятый в РФ.
- Цифровой товар с автоматической выдачей: программа, ключ, файл, шаблон.
- Подписки, услуги, физические товары, ИП и ООО опытом не покрыты. Скилл честно это скажет и будет проверять требования по источникам, а не выдумывать.

## Безопасность

- Пароли, ключи и токены Claude не просит, не выводит и не сохраняет. Их создаёшь и хранишь ты, в менеджере паролей.
- Деньги, возвраты и удаления — только ты или только после твоего явного «да».
- Живая оплата на сайте включается скриптом с предохранителем: страница не выложится, пока сервер в тестовом режиме.
- Персональные данные покупателей хранятся только в российских сервисах. Резервные копии зашифрованы.

## Ограничения

- Законы, цены и интерфейсы меняются. Опыт записан на конец 2026 года, поэтому перед каждой фазой скилл сверяется с актуальными источниками.
- Документы — образцы, а не юридическая консультация. Перед публикацией сверь их с юристом.
- Шаблон сервера проверен автотестом (38 проверок, подписи сверены с botocore). Живую базу и бакет можно проверить только при развёртывании. Скрипты `.cmd` собраны из команд, которые работали в реальном проекте, но целиком в таком виде ещё не запускались.
- Платёжка в шаблоне — Робокасса. Для другой нужен свой модуль.
