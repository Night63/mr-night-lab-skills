# Шаблоны

Обезличены: вместо реквизитов, доменов и названий — `{{ПЛЕЙСХОЛДЕРЫ}}`. Перед использованием Claude подставляет данные проекта из `project-state.md` и ищет оставшиеся `{{` поиском — их быть не должно.

| Папка | Что внутри | Проверено |
|---|---|---|
| `server/` | Сервер продажи для Cloud Functions (Python 3.12): `/buy`, `/order`, `/rk/result`, письма Postbox, шифрованные копии базы, чистка ПД, служебные `?r=` | автотест `tests/test_shop.py` (38 проверок, подписи SigV4 сверяются с botocore). Живой YDB и бакет — только при развёртывании |
| `site/` | Сборка двуязычных страниц (`build.mjs`), страницы документов (`doc.py`), служебные страницы (`page.py`), форма покупки, страница «Спасибо», тексты оферты, политики и согласия | вырезано из работающего сайта; вёрстку и стили делает дизайн-скилл под проект |
| `scripts/` | `.cmd` для Windows: выкладка сайта, выкладка оплаты с предохранителем, бакет копий и таймер, проверка функции без секретов | собраны из команд, которые работали на реальном проекте; целиком в этом виде не прогонялись — первый запуск читать по журналу |
| `forms/` | Значения для уведомления РКН, изменений, трансграничной передачи, заявки в платёжку | по реально поданным заявлениям; поля форм на порталах меняются |
| `project-state.md` | Файл состояния проекта | — |

Документы (`site/docs/*.txt`) — образец для лицензии на программу. Для другого товара разделы о ключе, активации и пробной версии переписываются. Это не юридическая консультация: перед публикацией сверить с юристом или с образцами Контура или Гаранта.
