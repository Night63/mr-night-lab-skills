# Mr Night Lab — скиллы для Claude

Коллекция полезных скиллов для Claude. Всё бесплатно, лицензия MIT.

- Telegram: https://t.me/mr_night_lab (там обсуждения и новые скиллы)
- YouTube: https://www.youtube.com/@Mr_Night_Lab

## Как установить скилл

1. Открой папку нужного скилла и скачай её.
2. Упакуй в ZIP так, чтобы внутри архива лежала папка скилла с файлом `SKILL.md`.
3. Добавь ZIP как пользовательский скилл в разделе скиллов в настройках Claude (название и расположение раздела зависят от версии приложения).

В README каждого скилла описано, что ему нужно (например, коннекторы).

## Скиллы

- [**chat-archive**](chat-archive/) — Чат архив: переносит знания между чатами через Google Диск. «Чат архив название» сохраняет выжимку, «Распаковка Чат название» подхватывает её в любом чате.
- [**site-konstruktor**](site-konstruktor/) — Сайт-конструктор: ведёт от нуля до продающего сайта цифрового товара в РФ (Yandex Cloud, Роскомнадзор, Робокасса, выдача товара). Claude делает сам всё, что может, а тебя зовёт только туда, где нужен ты.
