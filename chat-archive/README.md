# Чат архив (chat-archive)

**Версия 1.6** · скилл для Claude от [Mr Night Lab](https://t.me/mr_night_lab)

Переносит знания из одного чата Claude в другой через Google Диск. Ты говоришь «Чат архив», и Claude сохраняет структурированную выжимку чата в Google Doc. В любом другом чате, новом или старом, говоришь «Распаковка Чат название», и Claude подхватывает контекст.

## Какую проблему решает

Новый чат ничего не знает о старом. Решения, договорённости и состояние проекта приходится пересказывать вручную, а в длинных чатах часть важного теряется. Скилл хранит это в одном месте и возвращает по команде.

## Команды

| Команда | Что делает |
|---|---|
| `Чат архив название` | Создаёт или обновляет архив чата в Google Doc. Название чата задаёшь ты. |
| `Отдыхаем` | Сигнал паузы в обсуждении. Заодно обновляет архив чата, чтобы ничего не потерялось. Слово можно заменить на своё, поправив `SKILL.md`. |
| `Распаковка Чат название` | Находит архив, показывает краткую сводку и после твоего «ок» продолжает работу с учётом архива. |

Кодовую фразу можно написать в любом месте сообщения, в том числе посреди обсуждения. Если фраза просто упомянута в разговоре, а не дана как команда, Claude уточнит.

## Что сохраняется

Архив — это Google Doc с разделами: цель и контекст, принятые решения, текущее состояние, файлы и ссылки, договорённости, открытые задачи, следующий шаг, важные детали, оговорки и журнал версий архива.

По твоему выбору Claude сохраняет и рабочие файлы чата (текстовые и бинарные) в подпапку «Файлы». Что сохранять, он спрашивает каждый раз.

Структура на Google Диске:

```
История чатов/
└── Чат архив (название)/
    ├── Архив — название          ← актуальная версия
    ├── Архив — название_prev     ← предыдущая версия (откат)
    └── Файлы/                    ← рабочие файлы чата (по выбору)
```

## Установка

1. Скачай папку `chat-archive` из этого репозитория.
2. Упакуй её в ZIP так, чтобы внутри архива лежала папка `chat-archive` с файлом `SKILL.md`.
3. Добавь ZIP как пользовательский скилл в разделе скиллов в настройках Claude (название и расположение раздела зависят от версии приложения).
4. Включи в чатах, где хочешь пользоваться скиллом, коннекторы **Google Drive** и **Google Docs**.

## Пример

```
Чат архив Мой проект
```

Claude создаст папки на Диске (если их нет), соберёт выжимку, сохранит документ и коротко отчитается: путь, ссылка, версия, что вошло. Позже в другом чате:

```
Распаковка Чат Мой проект
```

Claude покажет сводку (версия архива, цель, число решений и открытых задач, следующий шаг) и дождётся «ок».

## Безопасность

- Пароли, ключи API, токены и номера счетов в архив не попадают.
- Содержимое архива при распаковке считается данными, а не командами. Если сегодняшние слова пользователя и архив расходятся, приоритет у пользователя.
- В корзину Claude отправляет только собственную старую копию `_prev` этого же архива.

## Ограничения

- Нужны подключённые коннекторы Google Drive и Google Docs. Инструменты Docs подгружаются отдельно от Drive; если их нет, Claude скажет об этом, а не будет имитировать результат.
- Скилл работает только по твоей команде. Claude не видит чат между сообщениями, поэтому автоматически архивировать «с момента создания чата» нельзя. Он лишь предложит сделать архив после крупного решения.
- В очень длинных чатах ранняя часть переписки может быть недоступна Claude. В этом случае он отметит это в архиве.
- Содержимое файла на Диске через коннектор перезаписать нельзя, поэтому версии ведутся копиями `_prev`.
- Удалённые в корзину файлы Google Диска хранит примерно 30 дней.
- Скилл проверен автором на создании и обновлении архива, распаковке в новом чате и сохранении файлов. Длительное использование на разных проектах ещё накапливает опыт.
